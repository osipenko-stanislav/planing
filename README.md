# Кадровое планирование

Прототип управления курсами, командой и вакансиями. Данные сохраняются локально в браузере.

## Запуск

```sh
npm ci
npm run dev
```

## Сборка

```sh
npm run build
```

GitHub Pages публикуется автоматически при обновлении `main`. Публичная версия использует hash-маршруты для поддержки прямых ссылок на статическом хостинге.
